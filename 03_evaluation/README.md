# 03 — Evaluation

> Measuring what LLMs can do: benchmarks, metrics, and model-based judges.

## Intent

Learn how LLMs are evaluated, where common benchmarks fall short, and how to build small, trustworthy evaluations for our own experiments.

## Research questions

- What do standard benchmarks actually measure, and how are they contaminated or saturated?
- How reliable is using an LLM as a judge, and what biases does it have?
- How should we evaluate the models produced in the other folders?
