# 00 — Foundations

> The building blocks of modern LLMs: the Transformer, attention, tokenization, and embeddings.

## Intent

Build a solid, hands-on understanding of how a decoder-only Transformer works, so that later topics (training, fine-tuning, inference) rest on a clear mental model.

## Research questions

- How does self-attention work, and what do positional encodings contribute?
- How do tokenizers (BPE, SentencePiece) shape what a model sees?
- What does a minimal GPT-style model look like when implemented from scratch?
